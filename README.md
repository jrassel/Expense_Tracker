# Expense Tracker Flutter

A simple Flutter application for tracking daily expenses using SharedPreferences for local data storage.

## Features

- Add daily expenses
- View all expense records
- Edit existing expenses
- Delete expenses
- Store expense data locally using SharedPreferences
- Expense fields:
    - Expense Title
    - Amount
    - Category
    - Date
    - Note / Description
- Basic form validation
- Clean and simple user interface

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- StatefulWidget
- ListView
- Form
- TextFormField
